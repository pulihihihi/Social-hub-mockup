# Sprout Drafts Source Brief

Captured: 2026-05-05
Source URL: `https://app.sproutsocial.com/publishing/drafts/`

## Baseline

- Page title: `Drafts`
- Header action: `Filters`
- Filter bar: `Draft Types`, `Profiles`, `Tags`, `Authors`, `Clear All`
- Default filter summary: `Viewing all`
- Empty state headline: `Draft now, publish later`
- Empty state body: `When you and your team members save drafts, you'll see them here.`
- Primary CTA: `Start a draft`
- Empty-state visual: simple draft/social post card with yellow border and skeleton content.

## Safe Filter Interactions

- `Draft Types` opens `All Post Types`, `Scheduled Drafts`, `Unscheduled Drafts`, plus personal activity filters.
- `Profiles` opens grouped Facebook, Instagram, TikTok, and YouTube profiles.
- `Tags` opens search, campaign/tag groups, reset, and match-all option.
- `Authors` opens avatar initials with author names.
- `Clear All` is disabled when no filters are selected.

## Intentional Non-Captures

- Did not click `Start a draft`, publishing nav destinations, destructive archive/delete areas, or account/help controls.
