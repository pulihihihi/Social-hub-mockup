## Summary
This package maps the actual New Post sections and state surfaces that the local AI runner can fill or review.

## Key Facts
- The current New Post surface covers caption, per-network captioning, first comment, media, alt text, subtitles, per-platform options, workflow, taxonomy, schedule, validation, and preview.
- AI section selection must align to real repo modules rather than to a simplified marketing-only flow.
- Generated patches should only target existing composer fields and existing option stores.

## How To Use
- Use this as the routing map for orchestration and for deciding which skills should run together.
