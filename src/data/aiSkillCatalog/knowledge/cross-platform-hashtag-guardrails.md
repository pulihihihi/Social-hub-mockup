## Summary
Guardrails for keeping hashtag output lightweight and platform-aware.

## Key Facts
- YouTube metadata depends more on title and description than tags; hashtag overload should be avoided.
- Short-form platforms benefit from concise, recognizable topic markers rather than large stacks of generic tags.
- Delta Force hashtag output should prefer a short core set and avoid spammy repetition.

## How To Use
- Use this when AI proposes hashtags or tag-like metadata in captions and comments.
