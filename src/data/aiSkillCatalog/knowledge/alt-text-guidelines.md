## Summary
W3C guidance for deciding what good alt text should communicate.

## Key Facts
- Alt text should describe the meaning or function of the image in context, not every visual detail by default.
- If text is already present nearby or the image is decorative, alt text can be empty in web contexts, but social publishing often benefits from concise informative text.
- Generated alt text should stay brief, specific, and context-aware.
